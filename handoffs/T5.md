## Done (backend, all in `sentinel/dashboard/`)
- `lib/bounds.mjs`: every cap, with the reason for its value and the failure mode on overflow. All caps fail loud
  (BoundExceededError → HTTP 413/507). Caps: MAX_CAPTURE_BYTES 8 MiB, MAX_CAPTURE_FILES 500,
  MAX_GRAPH_NODES 1000 (rows aggregate into one node, so the budget does not grow with data), MAX_ALERTS_PER_CAPTURE 500,
  MAX_PROVENANCE_EDGES_PER_ALERT 64.
- `lib/capture-loader.mjs`: indexes `captures/` (Map keyed by id; no paths are built from request input).
  It normalizes all real T1 shapes into `runs[]`: demo-ab (aim-ab runA RAGBot 7005 / runB RAGBot-AIM 7014),
  demo-ledger (repo beat2/beat3), demo-acts (flight act2/act3), benign `.req/.resp` pairs, and the
  generic OpenAI shape. Input bodies the capture did not record are marked `recorded:false` and are never invented.
- `lib/alert-adapter.mjs`: the single adapter for T4 `sentinel.alert/1.0.0`. It uses T4's `validateAlert`
  when present. Invalid alerts are kept and flagged, not dropped. The TaintPath `Kind:"truncated"` marker
  (`OmittedHops`) is preserved.
- `lib/replay.mjs`: pure, deterministic build of the graph, timeline, taint path and metrics. Hops are resolved by Map lookup
  on ToolCallId. Unresolved hops and the T4 truncation marker become **visible nodes**
  (`truncation_marker`, label "… N hops omitted (T4 TaintPath cap)"). If there are no alerts, a labeled
  `ground_truth` path is built from `dvaa{}`. Canary hits become `exfil_received` nodes. Trust score =
  100 − max Severity.
- `lib/alert-store.mjs`: alert sidecar lookup (`$SENTINEL_ALERTS_DIR`, `sentinel/scoring/alerts/`,
  `fixtures/alerts/` placeholder).
- `lib/scoring.mjs`: reads T7's `sentinel/scoring/results.json` when it exists. Otherwise the slot shows "awaiting T7"
  plus the real corpus counts. It never invents rates.
- `server.mjs`: `/api/captures`, `/api/replay?id=&run=`, `/api/scoring`, static files, bound to 127.0.0.1.
- Smoke-tested: replay builds for all 9 real captures (aim-ab runA/runB, repo, flight, benign) and returns 200.
- `test/fixtures/t4-sample-alert.json`: copied verbatim from T4 (`b51f32b`).
